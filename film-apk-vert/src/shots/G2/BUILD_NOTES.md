## 与分镜表的偏差（安全区/时长硬约束取舍，均已在注释标注）

1. **字号**：`v2 · one signature` 分镜写等宽 22px → 竖版最小 24px 规则（BUILD_RULES_VERT §2），取 24px；ParcelIcon 内置 `APK` 角标固定 21px，低于下限 → SC05 用组内自绘 24px 版（SC06 缩微态省略，同横版惯例）。
2. **SC05 火漆起点**：分镜「自上 stampIn」无坐标；scale 1.5 起始半径 180px，为使落章全程留在 y≥240 安全区（运镜 1.12 后世界坐标需 ≥266），cyStart 取 452（下落 28px + 尺度收缩表现"盖下"）。
3. **SC07 卡宽**：分镜 x 100–620 → 取 x 120–600（w 480），因 1.05 慢推下右缘不得越 x 620（世界坐标 ≤592 才安全），微调保证安全区。
4. **SC08 布局**：分镜 chip cy 800 size 300 → 取 cy 770 size 260 + `dex2oat` y 938；因 1.12 推镜下芯片下标签墨迹须 < y 1002（字幕带），分镜原坐标会越界。dex 卡 y 380–540 → 330–490（为齿轮/双侧箭头留纵向空间）。级联节拍：分镜「每格 3 帧 × 36 格 = 108f」在 121f 镜头内无法在入场后再完成 → 取 2f/格（70f，1252–1322，同横版 SC42 参考 2f/格），每格点亮视觉弹跳 ~3f。
5. **SC06 承接**：SC05 末运镜 s=1.12（像素连续无意义——SC05 末 8 帧已归零淡出），SC06 首帧以 scale 1.12 起步 16f 缩到 0.7，观感为"镜头切回封印包裹并拉远"。
