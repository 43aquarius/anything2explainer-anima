## 结构与复用
- `layout.tsx`：绝对帧 N 纯函数。`FilenameCard`（SC02 入场态 = SC03 完成态，镜头边界零跳变）、`EntryList`（SC04 滑出态 = SC05 点名态）、`ParcelBlock`（包裹 + HeroGlow 同盒，SC01→SC02 承接位移用）、`InstallBtn`/`ThumbGlyph`（SC02 复用时传同一 f0，入场公式自然处于完成态）、`FocusRing`、`PencilGlyph`、`GapGlow`。
- 图元：`ParcelIcon/PhoneMock/Box/CText` + fx 的 `CameraRig/HeroGlow/countTo`。示例文本全部取自 `EXAMPLE`（appName/fileName/appSize）；条目名 5 项来自分镜表 SC04 与 research §3（EXAMPLE 无此清单，已注释来源）。
- 相机承接链：SC01 末 (660,360,1.05) → SC02 252–268 回 (640,360,1) → SC03 340–373 推到 (640,400,1.15) → SC04 446–454 定格 → 454–484 拉回 (640,360,1) → SC05 静止。组界 870|871 全灭（末 8 帧归零），G2 SC06 清场重开。

## 对分镜表的偏离（待主会话裁定）
1. **Install 按钮位 (950,520)→(975,530)**：分镜表原位与包裹下 `120 MB` 计数文本碰撞（右缘距按钮左缘 <4px），右移 25px 留 23px 间隙。
2. **SC03 停留读数**：分镜表「`ZIP` 落位 373+21 → 离场 410−8」自相矛盾（402−394<30）。实现为交换 373–391 → 白闪 391–394 → GlitchIn 394（落位 406）→ 离场 437；满态停留 31 帧 ✓（≥30），整段 394–437 均为稳定期。
